The unrestricted affine hypothesis fails at four exact rational calibration sites when r>=6, so it cannot be used as a consistent predictor. The restricted r<=4 variant predicts 2/65 exact; r<=5 without cross-residue antisymmetry predicts 8/65. The primary model additionally imposes the observed signed residue-pair relations and yields 25/65 exact. These ablations are deliberately separated from the validated predictor.
